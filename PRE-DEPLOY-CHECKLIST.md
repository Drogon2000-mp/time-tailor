# Pre-Deployment Checklist for Render

Complete this checklist before deploying to Render to ensure a smooth deployment.

## ✅ 1. MongoDB Atlas Setup

- [ ] Created MongoDB Atlas account
- [ ] Created a cluster (free M0 tier is fine)
- [ ] Created a database user with read/write permissions
- [ ] Added IP address to Network Access (0.0.0.0/0 for Render or specific Render IPs)
- [ ] Copied connection string (format: `mongodb+srv://username:password@cluster.mongodb.net/timetailor`)

**How to get connection string:**
1. MongoDB Atlas → Clusters → Connect
2. Choose "Connect your application"
3. Copy the connection string
4. Replace `<password>` with your actual password
5. Replace `myFirstDatabase` with `timetailor`

## ✅ 2. Cloudinary Setup

- [ ] Created Cloudinary account (free tier is sufficient)
- [ ] Located credentials in Dashboard → Settings → Product Environment Credentials
- [ ] Noted down:
  - Cloud Name
  - API Key
  - API Secret

## ✅ 3. eSewa Setup (Optional for testing)

- [ ] Have eSewa merchant account OR use test credentials
- [ ] For testing: Use `EPAYTEST` as merchant ID (already configured)
- [ ] For production: Get actual eSewa credentials from eSewa

## ✅ 4. Local Build Test

Run these commands to ensure everything builds correctly:

```bash
# Clean install
npm ci

# Build client
npm run build

# Verify build output exists
ls -la client/dist

# Test server startup
npm start
# (Press Ctrl+C to stop after confirming it starts)
```

Expected output:
- ✅ Client build completes without errors
- ✅ `client/dist` folder contains `index.html` and `assets/` folder
- ✅ Server starts and connects to MongoDB
- ✅ Admin user is seeded
- ✅ Frontend is served from `/Users/.../client/dist`

## 📋 Deployment Steps

Once all checklist items are complete:

### Step 1: Create Service

1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click "New +" → "Blueprint"
3. Connect your repository
4. Select the branch (usually `main`)
5. Render will detect `.render.yaml` automatically

### Step 2: Configure Environment Variables

When prompted, set these **sync: false** variables:

```
MONGODB_URI=mongodb+srv://...
CLOUDINARY_CLOUD_NAME=your-cloud-name
CLOUDINARY_API_KEY=123456789012345
CLOUDINARY_API_SECRET=abcdefghijklmnopqrstuvwxyz
ESEWA_SECRET_KEY=your-secret-or-test-value
```

### Step 3: Deploy

1. Click "Apply" to create and deploy the service
2. Monitor the build logs
3. Wait for deployment to complete (5-10 minutes)

### Step 4: Verify Deployment

1. Visit: `https://time-tailor11.onrender.com`
2. Check health endpoint: `https://time-tailor11.onrender.com/api/health`
3. Try logging in with admin credentials:
   - Email: `admin@timetailor.com`
   - Password: `Admin@123`

## 🔍 Common Deployment Issues

### Build Fails with "Module not found"

**Cause**: Missing dependencies or incorrect workspace setup

**Solution**: Check build logs, ensure `npm ci` runs successfully

### "MongoDB connection failed"

**Cause**: Incorrect connection string or IP not whitelisted

**Solutions**:
- Verify `MONGODB_URI` is correct
- Check MongoDB Atlas Network Access
- Ensure cluster is not paused

### "Frontend not found" Warning

**Cause**: Build didn't complete or failed silently

**Solution**: Check that `npm run build` succeeded in build logs

### Service Won't Start

**Cause**: Missing required environment variables

**Solution**: Check all variables from Step 8 are set correctly
